#  Royal Ride – Luxury Car Rental Website

Royal Ride is a luxury car rental website designed to provide a premium vehicle booking experience. It features a collection of vintage cars, modern luxury sedans, premium SUVs and stretch limousines.

The website focuses on elegant design, easy navigation, vehicle selection and an interactive booking experience.

##  Features

- **Luxury Fleet:** Browse vintage and classic cars, luxury sedans, premium SUVs and stretch limousines.
- **Single Vehicle Images:** Each vehicle is displayed with one dedicated photograph.
- **Chauffeur Services:** Choose between a uniformed chauffeur and self-drive options where available.
- **Transparent Pricing:** View illustrative rental prices for both chauffeur-driven and self-drive options.
- **Rare Colour Selection:** Choose exclusive colours such as Champagne Gold, British Racing Green, Burgundy, Matte Black and Pearl White.
- **Dynamic Price Calculator:** Automatically calculates rental estimates based on the selected vehicle, package, chauffeur preference and colour.
- **Wedding Add-ons:** Optional flower and ribbon decoration.
- **Booking Form:** Enter personal details, pickup location, date, time and occasion.
- **Responsive Design:** Designed for desktop, tablet and mobile screens.

##  Pricing System

The website uses illustrative demonstration prices.

- Chauffeur-driven rental: Standard listed rate.
- Self-drive rental: 15% demonstration discount.
- Rare colour preference: 10% additional premium.
- Wedding decoration: ₹2,500 additional charge.

The final estimate changes automatically according to the customer's selections.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, layout and responsive design
- JavaScript – Vehicle filtering, booking form and price calculation
- Google Fonts – Typography
- Unsplash – Vehicle photography

##  How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the vehicle collection and test the booking calculator.

No additional installation is required.

##  Disclaimer

Royal Ride is an academic frontend demonstration project.

Vehicle information, contact details and rental prices are illustrative. The booking form does not process actual payments, send booking requests to a server or store customer information.
